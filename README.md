# Голосовые уведомления Orca

Локальные уведомления для Orca на macOS. Помощник выбирает WAV по событию и запускает системный `afplay`. Он не изменяет Orca и не отправляет данные по сети. Прогресс, открытие и закрытие сессии, отмена, замена запроса и звонок терминала не озвучиваются.

## Требования

- macOS, Python 3.9 или новее и запущенная Orca **1.4.261**. На других версиях схемы не проверены.
- Локальный профиль Orca. Для нестандартного профиля укажите `--profile /путь/к/профилю`.
- Свои WAV в одной папке. Репозиторий не включает голосовую модель, записи из Portal или синтезированные WAV. Используйте звук, на который у вас есть права.

## Установка

```sh
 git clone https://github.com/Maxunris/orca-voice-notifications.git
 cd orca-voice-notifications
```

1. Положите WAV в отдельную папку. Используйте имена из [`sounds.json`](sounds.json) или скопируйте этот файл и укажите свои имена.
2. Проверьте доступ к обоим источникам и формат файлов:
   ```sh
   python3 voice.py --sounds "$HOME/Voice WAV" --check
   ```
3. Прослушайте одну реплику:
   ```sh
   python3 voice.py --sounds "$HOME/Voice WAV" --play answer-ready
   ```
4. Установите помощник для текущего пользователя без `sudo`:
   ```sh
   python3 service.py install --sounds "$HOME/Voice WAV"
   ```
   Для своей карты добавьте `--config /путь/к/карте.json` к каждой команде. Для `--check` и `install` можно добавить `--profile /путь/к/профилю`.

Помощник стартует при входе в учётную запись. Не перемещайте папку WAV после установки. Если штатный звук Orca дублирует голос, выберите **Settings → Notifications → Notification sound → None**. При этом системные карточки можно оставить включёнными. Установщик не меняет эти настройки.

## События

| Статус | Встроенный чат | Терминал |
|---|---|---|
| `request-accepted` | Начался запрос с известным сообщением пользователя | Сохранено явное событие `UserPromptSubmit` для нового запуска |
| `answer-ready` | Явный исход `success` | Явный `mainAgent.outcome = success` |
| `question` | Открыт `question` | Известный инструмент вопроса |
| `permission` | Открыт `approval` | `PermissionRequest` с известным инструментом |
| `input-needed` | — | Агент ждёт ввода, тип не установлен |
| `error` | Явный `failure` | Явный `failure` |
| `interrupted` | `interrupted` | Явный `interruption` |
| `limit-reached` | Причина `usageLimitReached` связана с завершившимся запросом | — |
| `result-unconfirmed` | `unverifiable` | Явный `unconfirmed` |

Помощник читает `agent-session-domain.db` и `agent-hooks/last-status.db` в режиме SQLite `mode=ro`. Он не извлекает тексты запросов или ответов. Это внутренние форматы Orca, не стабильный API. Снимок терминала может пропустить короткий переход, который агент не сохранил или уже сменил. История до запуска помощника не озвучивается. Неизвестный исход не считается успехом. При распознанном лимите звучит одна реплика о лимите вместо общей ошибки.

Добавьте несколько имён WAV в массив нужного статуса, чтобы помощник выбирал случайный файл. При двух или более файлов последняя сыгранная реплика этого статуса исключается из следующего выбора. Удалите ключ из карты, чтобы отключить статус. [Тексты и ударения](phrases.md) можно использовать для своей озвучки.

## Состояние и удаление

```sh
launchctl print "gui/$(id -u)/io.github.maxunris.orca-voice-notifications"
python3 service.py uninstall
```

Журнал помощника: `~/Library/Application Support/Orca Voice Notifications/service.log`. Удаление отключает запуск и убирает plist, но не стирает аудио, копию конфигурации и журнал. Для обновления удалите службу и установите её снова.
